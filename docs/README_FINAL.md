# SpaceNet 8 Germany | Final statistics/report generator

This tool adds **no training**, does **not** change existing checkpoints, split IDs,
postprocessing, or thresholds, and does **not** require the original 2026 study to
be rerun. It only reads the data and test outputs already generated by the v6
experiment suite.

## Install

Extract this ZIP **in the project root**, alongside `exp.py` and `experiments_output/`.

```bash
unzip -o spacenet8_final_report_tools.zip
python -m pip install reportlab
```

You should already have `numpy`, `matplotlib`, `opencv-python-headless`, and `Pillow`
from the experiment suite. **No CUDA or PyTorch is needed to generate the report.**

## Run

```bash
python final_report.py
```

The script reads these existing runs:

- `v6_raw_bce_dice_balanced_e16_seed333` - best observed raw-RGB test IoU.
- `v6_augmentation_photometric_balanced_e16_seed333` - matched training-time augmentation contrast.
- `raw_bce_dice_seed111` - original raw-RGB control.
- `clahe_seed111` - deterministic CLAHE processing comparison.
- `matched_bce_seed111` and `augmentation_seed111` - other historical comparisons.

It requires existing `test_metrics.json` files for those runs, and stored
`.npy` probabilities for the two visual comparisons. Earlier `exp.py finalize`
commands produce those files. To produce a missing cache without any retraining:

```bash
python exp.py finalize --run experiments_output/runs/<run_id>
```

Note: **only use `finalize` for a run already tested**; do not alter your chosen
thresholds or interpret the rerun as a new independent test.

## Results

Under `experiments_output/final_report/` you will get:

- `SpaceNet8_Germany_Final_Report.pdf` - final illustrated report.
- `test_metric_comparison.png` - colored IoU/Dice bar comparison.
- `rgb_before_after_clahe.png` - actual same tile before and after CLAHE, plus luminance histograms.
- `test_confusion_matrices.png` - exact integer 2x2 confusion matrices for the raw, CLAHE, and photometric models (GT-row-normalized colors, counts annotated).
- `test_confusion_counts.csv` - TN, FP, FN, TP, IoU, Dice, precision, recall, accuracy.
- `raw_vs_clahe_overlays.png` - true paired raw-vs-CLAHE segmentation masks on the same test tiles.
- `raw_vs_photometric_overlays.png` - same raw input, comparing training augmentation.
- `test_performance.csv`, `v6_validation_comparison.png`, `report_provenance.json`.

The confusion counts are taken from the test metrics produced by full-precision
inference. **True negatives are computed from the total number of test-mask pixels**.
The cached `.npy` probabilities are float16, so they are used only for
visualization, not re-counting authoritative confusion values. The script verifies
that the saved counts align with ground-truth positive-mask totals.

## Interpreting the conclusion

Image processing was done: CLAHE, gamma, bilateral smoothing, sharpening and
chains were studied as deterministic input transformations, and photometric
augmentation as a training-only random brightness/contrast transform.

The controlled original raw-vs-CLAHE comparison yielded test IoU 0.5134 vs 0.5187.
The controlled v6 raw-vs-photometric comparison yielded 0.5229 vs 0.5114.
CLAHE had *no consistent three-seed validation advantage*, and **the best
observed v6 test model uses raw input**. The report makes these distinctions
explicitly rather than misreporting all processing as a gain.

Test metrics were inspected during the exploratory project and the geographic
split has neighboring tiles across groups. These are not official leaderboard
scores. The report documents these limitations.

## Preview mode (no dataset)

```bash
python final_report.py --summary-only --output preview_report
```

Summary-only mode uses uploaded aggregate results as reference values and
**never fabricates a confusion matrix** or before/after imagery. The complete
matrix and paired imagery require running normally from your prepared local
dataset.
